# HumanoidTH — สรุปสิ่งที่ปรับปรุงสำหรับส่งต่องาน

## ภาพรวมและเมนู

- จัดเมนูหลักไว้ด้านบนและแบ่งหมวดหมู่ให้หาแต่ละส่วนได้ง่ายขึ้น
- ปรับหน้า Overview ให้เป็นจุดเริ่มต้นสำหรับดูข้อมูลและไปยังส่วนต่าง ๆ ของระบบ
- ซ่อนเมนู Admin และ Database จาก navigation ของผู้ใช้ทั่วไป
- ปรับส่วนหัวบนมือถือและสไตล์ภาพรวมให้รองรับ layout ใหม่

## Dashboard

- ดึงและสรุปข้อมูลจากฐานข้อมูลจริง เช่น แหล่งข้อมูล รุ่นหุ่นยนต์ contributions และสถานะ pipeline
- แสดงกราฟและตัวชี้วัดในส่วนที่แยกจากเนื้อหาหลักของหน้า
- แสดงสถานะเมื่อฐานข้อมูลไม่พร้อม แทนการแสดงข้อมูลเสมือนว่าเป็นข้อมูลจริง

## Map

- เพิ่ม Data Map ที่แสดงขอบเขตจังหวัดจากข้อมูล GeoJSON สาธารณะ
- เพิ่มการค้นหาและเลือกจังหวัดเพื่อสำรวจข้อมูลในพื้นที่
- เพิ่มตัวเลือกสลับระหว่าง Data Map กับ Live Map
- ให้ Data Map ใช้งานได้โดยไม่ต้องใช้ Google Maps API key; key ใช้สำหรับ Live Map
- รองรับ fallback เมื่อไม่มี Gemini API key สำหรับการจัดกลุ่มสถานที่ด้วย AI

## Network

- ปรับการจัดวางกราฟและระยะห่าง เพื่อให้ node อ่านง่ายและไม่แน่นเกินไป
- ปรับรูปแบบ node และ edge พร้อมใช้สีสื่อความสัมพันธ์
- ปรับการระบุ edge เพื่อรวมความสัมพันธ์ที่ซ้ำกันระหว่างต้นทาง ความสัมพันธ์ และปลายทางเดียวกัน

## Robot Registry

- จัดรายการหุ่นยนต์ให้สำรวจและจัดกลุ่มได้ตามพื้นที่ ความใหม่ หรือความนิยม
- แสดงตำแหน่งเฉพาะ inventory ที่เปิดเผยเป็น public
- แสดงจำนวน contributions ที่เชื่อมโยงกับหุ่นยนต์แต่ละรุ่น

## Analytics

- เปลี่ยน Confidence Lens จาก scatter plot เป็น Histogram เพื่อให้เห็นการกระจายคะแนนได้ง่ายขึ้น
- เพิ่มสรุปจำนวนรายการที่มีคะแนน ค่าเฉลี่ย coverage และจำนวนรายการที่ควรตรวจทาน
- แบ่งระดับคะแนนเพื่อช่วยดูว่าข้อมูลส่วนใดน่าเชื่อถือหรือควรตรวจเพิ่ม

## การตั้งค่าฐานข้อมูล

- รองรับการใช้ direct database connection สำหรับคำสั่งจัดการ schema โดยยังใช้ connection หลักของแอปได้ตามเดิม
- ไม่มีการเพิ่ม API key ใหม่ในงานชุดนี้

## ข้อควรทราบสำหรับผู้รับช่วงต่อ

- การซ่อนเมนู Admin/Database เป็นการปรับ navigation ไม่ได้ยืนยันว่ามีการเพิ่มการป้องกันการเข้าถึง route โดยตรง
- หากไม่มี Gemini key ระบบควรใช้ fallback และไม่แสดงผลวิเคราะห์ AI ที่ไม่มีอยู่จริง
- Dashboard ควรใช้ข้อมูลจริง และแสดงสถานะชัดเจนเมื่อฐานข้อมูลใช้งานไม่ได้
